1. 有理数七上 第1-2章

来源：第1章 有理数 + 第2章 有理数的运算

概念

概念定义要点
正数/负数大于0的数是正数；在正数前加「-」号为负数；0既不是正数也不是负数。用正负数表示具有相反意义的量
有理数整数（正整数、0、负整数）与分数（正分数、负分数）的统称。分类：按定义分 / 按符号分（正有理数、0、负有理数）
数轴规定了原点、正方向、单位长度的直线。实数与数轴上的点一一对应（此处先对有理数成立）
相反数只有符号不同的两个数。a的相反数是-a；0的相反数是0。互为相反数的两点关于原点对称
绝对值数轴上表示数a的点与原点的距离，记|a|。正数的绝对值是它本身；负数的绝对值是它的相反数；0的绝对值是0。|a|≥0（非负性）
倒数乘积为1的两个数互为倒数。0没有倒数。a（a≠0）的倒数是1/a
乘方求n个相同因数积的运算：aⁿ（底数a、指数n）。负数的奇次幂为负，偶次幂为正
科学记数法把一个数写成 a×10ⁿ（1≤|a|<10，n为整数）的形式。把大于10的数记成 a×10ⁿ（n=整数位数-1）
近似数与实际接近的数。精确度：如3.14精确到百分位（百分位=0.01位）

运算法则

加法：同号相加取相同符号，绝对值相加；异号相加取绝对值较大者的符号，绝对值相减；互为相反数相加得0
减法：减去一个数等于加上它的相反数 a-b = a+(-b)
乘法：同号得正异号得负，绝对值相乘；除以一个不等于0的数等于乘它的倒数
混合运算顺序：先乘方，再乘除，后加减；有括号先算括号内
运算律：交换律 a+b=b+a、ab=ba；结合律 (a+b)+c=a+(b+c)；分配律 a(b+c)=ab+ac
中考考点：①绝对值/相反数化简（选填高频）②科学记数法（几乎每年必考，常结合大国重器/人口数据情境）③有理数大小比较（数轴法：右总大于左）④正负数表示相反意义量（实际情境题）

2. 实数七下 第8章

概念

概念定义要点
平方根若x²=a（a≥0），x是a的平方根，记±√a。正数有两个平方根（互为相反数）；0的平方根是0；负数没有平方根
算术平方根正的平方根，记√a（a≥0）。双重非负性：a≥0 且 √a≥0。√0=0
立方根若x³=a，x是a的立方根，记∛a。正数、负数、0都有唯一立方根；∛(-a)=-∛a
无理数无限不循环小数。常见来源：√2、π、特定结构的小数（如0.1010010001…每两个1之间依次多一个0）
实数有理数与无理数的统称。实数与数轴上的点一一对应。实数按大小分类：正实数、0、负实数

运算

√a·√b = √(ab)（a≥0,b≥0）；√a / √b = √(a/b)（a≥0,b>0）〔七下先接触，八下系统化〕
实数运算顺序与运算律同有理数；涉及无理数取近似值计算
中考考点：①平方根/算术平方根/立方根辨析（选填高频，注意「√16的算术平方根=2」类陷阱）②无理数识别 ③实数大小比较/估算（如判断√10在哪两个整数之间）④非负数性质：若|a|+√b=0 则 a=0,b=0（经典模型）

3. 代数式与整式加减七上 第3-4章

概念

概念定义要点
代数式用运算符号把数或字母连接而成的式子。单独一个数或字母也是代数式
列代数式把文字语言的数量关系翻译成符号语言；注意「a与b的差」「a的2倍与b的和」等表述顺序
代数式的值用数值代替代数式里的字母，按式子中的运算关系计算得出的结果
单项式数与字母的积。系数=数字因数，次数=所有字母指数的和
多项式几个单项式的和。次数=次数最高项的次数；项数=所含单项式个数（常数项也是一项）
整式单项式与多项式的统称
同类项字母相同且相同字母的指数也相同（与系数、字母顺序无关）。几个常数项也是同类项

法则与公式

合并同类项：系数相加，字母和指数不变
去括号：括号前是「+」去括号不变号；括号前是「-」去括号各项变号。（注意分配律漏乘：-3(x-2y)=-3x+6y）
整体思想：a+2b=3，求 2a+4b-1 = 2(a+2b)-1 = 5（北京卷选填爱考整体代入）
中考考点：①找规律/程序框图求代数式的值（北京卷特色题型）②整体代入求值 ③化简求值综合（与后面分式、二次根式结合）

4. 幂运算 · 整式乘法 · 乘法公式 · 因式分解八上 第16-17章

幂的运算法则（底数不变类）

同底数幂相乘：aᵐ·aⁿ = aᵐ⁺ⁿ（乘加）
幂的乘方：(aᵐ)ⁿ = aᵐⁿ（乘）
积的乘方：(ab)ⁿ = aⁿbⁿ（分配）
同底数幂相除：aᵐ÷aⁿ = aᵐ⁻ⁿ（a≠0）；a⁰=1（a≠0）；a⁻ᵖ=1/aᵖ（a≠0）〔整数指数幂，八上18.4〕

整式乘法

单项式×单项式：系数相乘，同底数幂相乘
单项式×多项式：m(a+b)=ma+mb
多项式×多项式：(a+b)(m+n)=am+an+bm+bn（不重不漏）

乘法公式（两大恒等式）

平方差：(a+b)(a-b) = a²-b² 〔特征：两项和×两项差〕
完全平方：(a±b)² = a²±2ab+b² 〔特征：首平方尾平方，积的2倍在中央〕
〔拓展〕(a+b)²-(a-b)²=4ab；a²+b²=(a+b)²-2ab（配方常用变形）

因式分解（整式乘法的逆运算）

一提：提公因式法 pa+pb = p(a+b)〔公因式=系数最大公约数×相同字母最低次幂〕
二套：公式法 a²-b²=(a+b)(a-b)；a²±2ab+b²=(a±b)²
三检验：分解要彻底（到不能再分为止）；结果为积的形式
〔拓展·中考压轴〕十字相乘 x²+(p+q)x+pq=(x+p)(x+q)；分组分解法
中考考点：①幂运算辨析选填（a³·a²=a⁵ vs (a³)²=a⁶ 是高频陷阱）②乘法公式正用逆用（北京卷选填常考用平方差简便计算）③因式分解是分式化简/一元二次方程解法的前置技能（解答题必用）④配方法（完全平方公式逆用）是二次函数求顶点、一元二次方程求根的核心动作

5. 分式八上 第18章

概念

概念定义要点
分式形如A/B（A、B为整式，B中含有字母且B≠0）。分式有意义⇔B≠0；分式值为0⇔A=0且B≠0
基本性质A/B = (A×M)/(B×M) = (A÷M)/(B÷M)（M≠0）。约分与通分的依据
最简分式分子分母没有公因式的分式

运算法则

乘除：A/B · C/D = AC/BD；A/B ÷ C/D = A/B · D/C（除法变乘法，颠倒除式）
加减：同分母 A/C±B/C=(A±B)/C；异分母先通分（最简公分母=系数最小公倍数×相同字母最高次幂）
乘方：(A/B)ⁿ = Aⁿ/Bⁿ

分式方程

解法：去分母（两边同乘最简公分母）→解整式方程→检验（代入最简公分母，=0为增根舍去）
应用：行程/工程/购买问题。验根之外还要检验实际意义
中考考点：①分式化简求值是北京卷解答题固定题型（先化简再代入，代入值需避开使分母为0的数）②分式有意义/值为0的条件（选填）③分式方程应用（注意双检验）④增根概念辨析

6. 二次根式八下 第19章

概念与性质

条目内容
二次根式形如√a（a≥0）的式子。双重非负性：被开方数a≥0，结果√a≥0
性质1(√a)² = a（a≥0）
性质2√(a²) = |a| = a（a≥0）或 -a（a<0）〔化简核心，易错点〕

运算法则

乘除：√a·√b=√(ab)；√a/√b=√(a/b)（a≥0,b>0）
加减：先化简（化成最简二次根式），再合并同类二次根式（被开方数相同）
最简二次根式：被开方数不含分母、不含能开尽方的因数。如√8=2√2，√(1/2)=√2/2
分母有理化：1/√2 = √2/2（分子分母同乘√2）
中考考点：①二次根式化简求值（解答题计算题常客）②√(a²)=|a|类化简陷阱（选填）③有意义的条件（被开方数≥0同时成立）④与勾股定理/三角函数结合的精确计算

7. 方程体系（一元一次 → 二元一次 → 三元 → 一元二次）七上第5章 / 七下第10章 / 九上第25章

概念

概念定义要点
方程/方程的解含未知数的等式叫方程；使方程左右两边相等的未知数的值叫方程的解
一元一次方程只含一个未知数、未知数次数为1的整式方程：ax+b=0（a≠0）
等式的性质①两边同加减同一个数（式）仍相等 ②两边同乘一个数、或同除以不为0的数，仍相等（变形依据）
二元一次方程组两个二元一次方程合在一起。解的检验：代回两个方程都成立
一元二次方程ax²+bx+c=0（a≠0）。二次项系数/一次项系数/常数项
根的判别式Δ=b²-4ac：Δ>0两个不相等实根；Δ=0两个相等实根；Δ<0无实根（反之亦然）
根与系数关系〔韦达定理·拓展〕x₁+x₂=-b/a，x₁x₂=c/a（前提Δ≥0）

解法

一元一次方程五步：去分母→去括号→移项→合并同类项→系数化为1
二元一次方程组：代入消元（用一个未知数表示另一个）、加减消元（同号相减异号相加）。核心思想：消元（二元→一元）
三元一次方程组〔拓展〕：逐步消元降维
一元二次方程四法：①直接开平方法（x²=p型）②配方法（x²+px+q=0 → (x+p/2)²=(p²-4q)/4）③公式法 x=(-b±√Δ)/2a（万能）④因式分解法（化归为两个一次方程，最快）

应用模型（北京卷应用题题库）

行程：路程=速度×时间（相遇/追及/顺逆流：顺流速=静水+水速）
工程：总工作量=工作效率×时间（常设总量为1）
利润：利润=售价-进价；利润率=利润/进价；打折：售价=标价×折扣
增长率：a(1+x)ⁿ=b（n期）；面积/拼接问题（列一元二次）
方案选择：结合不等式取整数解，比较总费用（北京卷高频大题）
中考考点：①解一元二次方程（配方法/公式法过程规范）②根的判别式正用反用（选填高频：「关于x的方程有两个不相等实根求m范围」注意二次项系数≠0）③应用题建模（行程/工程/增长率/销售）④二元一次方程组与一次函数图象交点结合（选填）

8. 不等式与不等式组七下 第11章

概念与性质

条目内容
不等式用「＞≥＜≤≠」表示大小关系的式子。不等式的解集：使不等式成立的未知数的取值范围
性质1两边加减同一个数（式），不等号方向不变
性质2两边同乘（除）正数，方向不变
性质3两边同乘（除）负数，不等号方向改变（北京卷最爱考的易错点）
解集表示数轴表示：≥≤实心点，＞＜空心圈，方向向右/向左

解法与应用

一元一次不等式：同解方程五步，但两边乘除负数时变号
不等式组解集口诀：同大取大、同小取小、大小小大中间找、大大小小找不到（无解）
应用：设未知数→列不等式（找「至少/不超过/不超过」关键词）→解集→按实际取整数解→作答（方案问题）
中考考点：①不等式性质辨析（选填）②解不等式组并用数轴表示解集（解答题）③方案选择应用题（不等式建模+整数解+费用比较，北京卷应用大题常客）④与一次函数结合：图象上方/下方对应解集

9. 函数总论八下 第22章（新版单列章）

概念

概念定义要点
变量与常量变化过程中数值发生变化的量为变量，始终不变的量为常量
函数在一个变化过程中，有两个变量x和y，对于x的每一个确定的值，y都有唯一确定的值与其对应，x叫自变量，y叫x的函数
自变量取值范围①整式：全体实数 ②分式：分母≠0 ③根式：被开方数≥0 ④实际背景：符合实际意义（北京卷选填常考）
函数的表示①解析式法 ②列表法 ③图象法。判断函数图象：过自变量每点作垂线，与图象至多一个交点（竖线判别）
函数图象满足解析式的点(x,y)的集合。描点法画图象：列表→描点→连线
中考考点：①函数图象信息读取（行程图/注水问题过程分析，北京卷选填经典题型）②自变量取值范围（复合条件求交集）③函数概念判断（y唯一对应）④从图象估算/结合实际情境解释（新课标强化情境化）

10. 一次函数八下 第23章

概念与图象

条目内容
正比例函数y=kx（k≠0），图象是过原点的直线
一次函数y=kx+b（k≠0），图象是直线；b为图象与y轴交点纵坐标（截距）
图象画法两点法：取(0,b)与(-b/k, 0)
增减性k＞0：y随x增大而增大（图象上升，必过一三象限）；k＜0：y随x增大而减小（下降）。b决定与y轴交点在正/负半轴
图象过象限k＞0,b＞0过一二三；k＞0,b＜0过一三四；k＜0,b＞0过一二四；k＜0,b＜0过二三四
待定系数法两点代入 y=kx+b 解方程组求k、b（求解析式的通用方法）

函数与方程/不等式的关系（数形结合核心）

kx+b=0 的解 ⇔ 直线与x轴交点横坐标
kx+b＞0 的解集 ⇔ 直线在x轴上方部分对应的x范围
两直线交点 ⇔ 二元一次方程组的解；交点上方/下方 ⇔ 比较函数值大小（谁图象在上面谁大）
平移：y=kx+b 向上平移m个单位 → y=kx+(b+m)（上加下减，沿y轴）；沿x轴左加右减
中考考点：①图象性质判断（k、b符号与图象位置互推，选填高频）②待定系数求解析式（解答题第一问常设）③一次函数与方程不等式综合（选填压轴常客）④实际应用：行程分段计费/最优方案（b的横截距与拐点分析，北京卷大题）⑤与几何结合：动点问题中的函数图象判断

11. 反比例函数九上 第27章

概念与性质

条目内容
定义y=k/x（k≠0）或 xy=k。等价形式 y=kx⁻¹
图象双曲线，两支分别位于一三象限（k＞0）或二四象限（k＜0），无限接近坐标轴但永不相交（渐进性）
增减性k＞0：在每个象限内y随x增大而减小；k＜0：每个象限内y随x增大而增大。必须强调「在每个象限内」（跨象限不比较）
k的几何意义过双曲线上任一点作两坐标轴垂线，围成矩形面积=|k|；三角形面积=|k|/2（北京卷选填压轴高频模型）
待定系数法知道一点即可求k（一点定k）
中考考点：①k的几何意义（矩形/三角形面积模型，与一次函数交点、平移结合出选填压轴）②图象性质与待定系数 ③实际应用：压强/杠杆/浓度反比关系（p=F/S类情境）④与一次函数联立求交点（解答题中档）

12. 二次函数九上 第26章（中考压轴之王）

三种解析式形式

一般式：y=ax²+bx+c（a≠0）；顶点(-b/2a, (4ac-b²)/4a)；对称轴x=-b/2a
顶点式：y=a(x-h)²+k；顶点(h,k)，对称轴x=h
交点式：y=a(x-x₁)(x-x₂)（x₁x₂为与x轴交点横坐标）
配方法：y=ax²+bx+c → y=a(x+b/2a)²+(4ac-b²)/4a（配方法动作必须熟练）

图象与性质

条目内容
开口方向a＞0开口向上（有最低点/最小值）；a＜0开口向下（有最高点/最大值）；|a|越大开口越小
对称性抛物线关于直线x=-b/2a对称；对称轴两侧等距点函数值相等（f(h+m)=f(h-m)）
增减性a＞0：对称轴左侧递减右侧递增；a＜0相反。比较函数值先看与对称轴的距离

18. 圆九上 第29-30章

基本概念

条目内容
圆到定点的距离等于定长的点的集合。定点=圆心，定长=半径。确定圆的要素：圆心+半径
弦/弧连接圆上两点的线段=弦（过圆心的弦=直径）；圆上任意两点间的部分=弧（半圆/优弧/劣弧）
圆心角/圆周角顶点在圆心/圆上（圆周角两边与圆相交）

定理与性质（圆的核心定理群）

垂径定理：垂直于弦的直径平分弦，并且平分弦所对的两条弧〔逆定理：平分弦（非直径）的直径垂直于弦〕——2022课标调整为必修。推论应用：半径²=r²=(弦心距)²+(半弦)²〔勾股构造是圆计算的核心动作〕
弧弦圆心角关系：在同圆或等圆中，相等的圆心角所对的弧相等、弦相等（三者等价转换）
圆周角定理：同弧所对圆周角=圆心角的一半；推论①：同弧（等弧）所对圆周角相等〔2022课标新增为基本要求〕；推论②：直径所对圆周角是直角（90°圆周角所对弦是直径）〔圆中找直角的工具〕
圆内接四边形〔拓展〕：对角互补；外角=内对角

点、直线与圆的位置关系

点与圆：d＜r在圆内；d=r在圆上；d＞r在圆外（d=点到圆心距离）
直线与圆：相交（d＜r，两个公共点）→割线；相切（d=r，唯一公共点）→切线；相离（d＞r）
切线性质：切线垂直于过切点的半径（常连半径证垂直）切线判定：经过半径外端且垂直于这条半径的直线是圆的切线（有公共点连半径证垂直；无公共点作距离证等于半径）
切线长定理：从圆外一点引圆的两条切线，切线长相等；圆心与该点连线平分两切线夹角〔2022课标：探索切线与过切点半径的关系为选学，北京卷仍常考〕
三角形内切圆：内心=三条角平分线交点，到三边距离相等；Rt△内切圆半径 r=(a+b-c)/2〔拓展〕

计算公式

弧长 l = nπr/180（n为圆心角度数）
扇形面积 S = nπr²/360 = ½lr（弧长×半径一半，类比三角形）
圆锥侧面积 = πrl（l为母线长）；全面积 = πrl+πr²。圆锥侧面展开图=扇形（弧长=底面圆周长）
正多边形与圆：正n边形中心角=360°/n；每边所对弧相等；半径、边心距、半边构成直角三角形〔计算核心〕
中考考点：①垂径定理计算（弦长/拱高，勾股方程）②圆周角定理推理链（同弧等角、直径直角）③切线的判定证明（北京卷圆类解答题固定动作：连半径证垂直）④弧长扇形面积计算（选填）⑤圆锥侧面展开⑥圆与相似/三角函数结合〔压轴〕

方差s²=(1/n)·Σ(xᵢ-x̄)²。方差越小数据越稳定；标准差=√方差（量纲还原）

概率（九下第34章）

随机事件：必然事件（P=1）、不可能事件（P=0）、随机事件（0＜P＜1）
概率定义：刻画随机事件发生可能性大小的数值。P(事件A)=m/n（等可能结果中事件A包含的结果数/总结果数）
列举法：列表法（两步试验）；画树状图法（两步及以上，如三步取球）。注意「放回/不放回」区别〔北京卷解答固定题〕
用频率估计概率：大量重复试验中频率稳定于概率；频率≠概率但可估计
