🧗 安装困难 TOP 主题（35/49 人反馈）

12人 · 首要主题🧵 隐藏走线/排线难，费时费力

「翘车辆缝隙盖板之类，隐藏走线这些比较麻烦费时间」——陈占学
「A柱的拆解跟密封圈的拆解比较怕破坏掉」「扒B柱等地方（气囊）的缝隙难拨开」——郑惟环/秦世游
「后摄的线不好走，后摄的那个插口有点粗…建议全部采用type c的接口线」——陶双
「OBD和后摄走线，占用一大半时间」「OBD设备穿线拆盖板比较费时间，安装完后原先盖板无法归位」——苏冬冬/闫鹰飞

9人提及🔄 后摄无方向标识 → 装反重装

「后摄没有标安装方向。且后摄没有上下画面反转功能，导致第一次安装后发现后摄画面上下反了，重新再装」——王刚红（安装总体6分根因）
「后录装反了，画面颠倒，又重新装的」——公海军
「后摄无明显方向指示，安装方向（上下）容易安装反，要先看看实时画面才能粘后摄」——方家欢

5人📍 安装位置选择难 / 左摄被后视镜遮挡

「主机位置的确定，因为车型原因，左副摄总是会被后视镜遮挡」——张宁×2次反馈
「有些车型要和后视镜同一水平，后视镜会遮挡左摄」「左摄视野和后视镜有干涉」——2位用户
「记录仪水平问题，就用眼睛估量多少有点偏差啦，建议底座增加水平仪」——汪杨

4人📦 4G云盒安置受限

「云盒上的2个Type-C不能混用，所以云盒的安装位置挺受限」——李栋灵
「OBD降压线多余的线放在保险盒内，保险盒打开和盖上比较麻烦」——程玢泽

其他零散🧰 工具与配件

「撬棒不好用，加个弯钩就可以更好的埋线」——娄泽彬
「给了两根安装线一长一短…以为每个线都要插上，结果拔了插插了拔找不到多出来的插口。建议说明书/视频里提一嘴两根线按车型二选一」——张鹏鑫

✅ 结论与改进建议

优先级结论影响面
P1后摄方向标识缺失：无上下方向指示且无画面翻转功能，导致装反重装，是安装总体低分（6分）的直接根因。建议：后摄本体加方向箭头/标识 + 说明书视频明确标注；软件侧评估「画面上下翻转」功能可行性9人提及 · 3人实锤装反重装
P1隐藏走线是最大时间成本：72%用户安装耗时≥30分钟，主要耗在走线/拆盖板/藏线。建议：安装视频补充各车型走线参考（用户点名参考抖音教程式呈现）；评估后摄无线化/Type-C统一接口的长期方案12人首要主题 · 29/41自装用户≥30min
P24G云盒安置与接口辨识：双Type-C不能混用但标识不明显，云盒线粗过硬难藏。建议：接口丝印/颜色区分+文字标注；连接线评估细化；赠送夹板/收纳位4~6人
P2左摄与后视镜干涉：部分车型主机位置受限，左摄被后视镜遮挡。建议：说明书给出「先试位后粘贴」指引+水平仪辅助；评估左摄延长线配件5人（2人视野明显受损）
P3后录接线偏长：低分2例均为「太长」。建议：按车型分级配线或附扎带收纳方案2人低分 · 多人吐槽
P3连接侧体验良好：一次绑定率88%，六维均分9.65+，扫码直连、远程设置、远程电压查看为锦上添花项，纳入需求池排期评估需求池候选 8条
总体判断：G980H 4G 安装体验整体优秀（九维均分≥9.3，自装率84%证明上手门槛低），核心改进点集中在后摄方向标识与走线效率两项，均为低成本可落地改进。
