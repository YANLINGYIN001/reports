🎯 改进建议汇总

  • P0 优化AI人形检测算法 — 误报18条占16.5%为最大痛点，需降低无人场景下的误触发率，提升人形识别准确度，减少无效云录和消息通知
  • P0 修复视频流加载链路 — 开流失败5条+漏录6条+回放卡顿3条，4G网络下实时画面加载需专项优化，排查从推流到播放的全链路瓶颈
  • P0 修复卡录远程查看异常 — 乱码、黑屏、无法读取等问题集中出现，需排查远程调取卡录的编解码和传输逻辑
  • P1 优化录像触发响应速度 — 人走过去才触发录像，需缩短PIR/AI检测到录像启动的延迟，确保完整记录事件
  • P1 修复事件分类准确性 — 路过被分类为逗留、画面变化被识别为人员出现，需优化事件分类模型和阈值
  • P1 修复APP状态同步问题 — 切换联网方式后页面不刷新、设置项自动重置、云录卡录时间不同步等需统一排查
  • P1 优化4G/WiFi切换可靠性 — 4G切WiFi失败、强拆提示网络错误等，需加强网络切换的容错和重试机制
  • P2 优化续航表现 — 耗电快问题需排查待机功耗，评估可拆卸电池方案的可行性
  • P2 评估用户功能需求 — 变声功能（保护独居女性隐私）、可拆卸电池等需求建议纳入产品迭代规划
  • P2 改善包装和硬件细节 — 加强物流包装保护，优化外壳材质和按键手感
